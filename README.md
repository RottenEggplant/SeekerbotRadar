# Seekerbot Radar

Track the Seekerbot's location, distance, and current activity in Survival.

## Install

1. Extract the ZIP.
2. Close Scrap Mechanic.
3. Double-click **Install.cmd**. Keep the **SeekerbotRadar** folder beside it.
4. Start the game, open the logbook (**L**), and turn **SEEKERBOT RADAR: ON**.

The installer finds your Steam installation automatically. If prompted, select your Scrap Mechanic game folder.

## Use

The radar is available immediately, with no crafting required. It starts OFF and remembers your ON/OFF setting. Use the logbook button to switch it at any time.

- **Compass marker:** shows the Seekerbot's direction and distance. Green means farther than 1 mile, yellow means 500 yards to 1 mile, and red means closer than 500 yards. Enable the compass in the game's settings to see it.
- **Upper-right indicator:** green while SEEKING; gray while ASCENDING, RELOCATING, DESCENDING, or INACTIVE.
- **Alerts:** a ping when the Seekerbot finishes seeking; a ping and a brief center-screen warning when it begins seeking. If it is already seeking when you load in, it will also ping with the warning.

Turning the radar OFF hides its indicators and silences its alerts.

The host can type **/radar next** in chat to make a seeking Seekerbot move to its next location.

## Uninstall

Close the game and double-click **Uninstall.cmd**.

If a game update or Steam file verification removes the mod, close the game and run **Install.cmd** again.
